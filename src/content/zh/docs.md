# 安装 APK {#install}

1. 打开 [下载中心](/download)，下载最新版 APK（文件名形如 `WQs-Proxy-VPN-1.3.0-arm64-v8a.apk`）。下载链接指向 GitHub Releases。
2. 按下载中心的说明核对 **SHA-256**，确认与页面显示的值完全一致。
3. 在手机上打开该 APK。系统通常会提示「此来源的应用未获授权安装」之类的信息，需要在弹出的设置页里允许当前浏览器或文件管理器「安装未知应用」，然后返回继续安装。
4. 安装完成后，可以回到系统设置把「安装未知应用」权限重新关闭。

> **为什么会出现安全提示？** 应用不是从应用商店安装，并且使用的是 Android **debug 签名**（不是正式发布签名）。部分系统（例如国内厂商系统）或安全软件还可能进行额外扫描或给出风险提示。请只从本站链接到的 GitHub Releases 下载，并核对 SHA-256。

**设备要求**：Android 7.0 及以上（minSdk 24）、arm64-v8a 处理器。32 位 ARM 或 x86 设备无法安装。各 Android 版本上的实际表现 ==待验证==。

## 从旧版本升级 {#upgrade}

- 从 **1.1.1 及以后**的版本升级：可以直接覆盖安装（签名证书相同）。
- 从 **1.0.0 或 1.1.0** 升级：必须先卸载旧版，否则系统会提示「安装包与已安装的应用签名不一致」或安装失败。卸载会删除应用内的全部节点、订阅和设置（应用关闭了 Android 系统备份），1.0.0 / 1.1.0 也没有导出功能，请事先保存好原始分享链接或订阅地址，升级后重新导入。

# 首次启动与权限 {#first-launch}

- **VPN 授权**：第一次点击连接时，应用会调用系统的 VPN 授权流程，系统会弹出「连接请求」对话框，需要点「确定」。如果拒绝，应用会提示未授权，不会建立连接。
- **通知权限**（Android 13 及以上）：应用启动时会请求通知权限，用于显示 VPN 前台服务通知（显示连接状态，并提供「断开」按钮）。拒绝通知权限不影响你在应用内操作，但可能看不到状态通知。
- **相机权限**：只有在你选择「扫码导入」时才会请求。拒绝后仍可用「从相册图片识别」导入二维码。
- **相册**：从相册识别二维码使用系统的照片选择器（Android 13 及以上不需要存储权限）。

以上授权流程按源码实现编写，在不同厂商系统上的具体弹窗样式与行为 ==待验证==。

# 支持的协议 {#protocols}

| 协议 | 说明 |
|---|---|
| Shadowsocks | 支持 2022-blake3-aes-128-gcm / 2022-blake3-aes-256-gcm / 2022-blake3-chacha20-poly1305 及传统 AEAD 加密 |
| VMess | 可选 TLS 与传输层 |
| VLESS | 支持 REALITY（需要公钥 pbk）与 xtls-rprx-vision（仅 TCP 传输） |
| Trojan | 通常与 TLS 配合使用 |
| Hysteria2 | 可选 salamander 混淆 |
| TUIC | 可设置拥塞控制与 UDP 中继模式 |
| SOCKS5 | 可选用户名 / 密码 |
| HTTP | 可选用户名 / 密码；没有通用分享链接格式，需要手动添加或通过 sing-box JSON 导入 |

传输层支持 TCP、WebSocket、gRPC、HTTP、HTTPUpgrade。生成的配置在启动前会经过 sing-box 内核的配置校验。**不支持**：ShadowsocksR、NaïveProxy、Hysteria v1、WireGuard 链接、AnyTLS 链接（导入时会明确提示）。各协议与真实服务器的互通情况 ==待验证==。

# 导入节点 {#import}

在「节点」页的「添加节点」菜单中可以：

- **粘贴导入**：支持 `ss://`、`vmess://`、`vless://`、`trojan://`、`hysteria2://`、`hy2://`、`tuic://`、`socks://` / `socks5://` 分享链接，可以一次粘贴多行；也支持 Base64 编码的订阅内容和 sing-box JSON（含 outbounds）。打开导入对话框时，如果剪贴板里的文字包含 `://`，会自动预填进输入框。
- **添加订阅**：填写 http(s) 订阅地址，应用会下载订阅（上限 5 MB）、解析并导入。之后可以手动刷新订阅。
- **扫码导入**：用相机扫描节点二维码 ==待验证==。
- **从相册图片识别**：选择一张包含二维码的图片。
- **手动添加**：在编辑器里逐项填写。

导入时会逐条校验，格式错误或不受支持的条目会被拒绝并说明原因，重复的节点会被跳过。识别到的二维码如果是单个 http(s) 地址，会被预填到「添加订阅」，其他类型（例如 Wi-Fi 二维码）会被拒绝。

**导出**：选中节点后可以复制分享链接、复制 Base64 订阅、通过系统分享发送，或显示二维码（内容过长时不可用）。导出的内容包含密码、UUID 等凭据，请只发给信任的人。

# 路由模式 {#routing}

| 模式 | 行为 |
|---|---|
| 自动分流（默认） | DNS 流量交给内置 DNS；局域网 / 私有地址直连；命中「直连域名」后缀的直连；命中「代理域名」后缀的走代理；其余全部走代理 |
| 全局代理 | 除局域网与保留地址外，所有流量经所选节点 |
| 直连模式 | VPN 接管流量但全部直连，用于排查或对比 |

自动分流**不包含** GeoIP / GeoSite 规则库，只使用你自己设置的域名后缀列表。默认的远程 DNS 是 `https://1.1.1.1/dns-query`（经代理），直连 DNS 是 `223.5.5.5`（用于解析节点服务器地址和直连域名），都可以在设置中修改。

# 延迟检测与分组 {#latency}

检测结果会注明属于哪一层，不会把低层成功说成节点可用：

- **仅 TCP**：VPN 未开启时，只验证服务器端口能连上。
- **TLS 握手**：端口可连且 TLS 证书校验通过，但没有验证代理认证。
- **代理请求**：VPN 开启时，经 sing-box 用该节点实际完成一次 HTTP 请求（默认目标 `https://www.gstatic.com/generate_204`），这才代表节点可用。

Hysteria2 / TUIC 基于 UDP，VPN 未开启时会显示「不适用」。「检测…」可以选择全部节点、当前筛选结果或某个分组；每个分组标题也有「检测本组」。「进入节点页自动检测」是设置项，默认关闭。

**分组与排序**：不分组 / 按来源 / 按协议 / 自定义分组；排序可选默认顺序、按延迟、按名称。自定义分组可以新建、重命名、删除，订阅刷新后节点仍留在原分组。分组只影响显示，不改变节点或生成的配置。

**删除失效节点**：删除最近一次检测失败或超时的节点，删除前会列出名单让你确认。

# 风险节点 {#risk}

- **高风险**：节点设置了跳过 TLS 证书校验（insecure / allowInsecure），可能被中间人冒充服务器、窃取账号。这类节点默认**不会**写入运行配置，连接前必须对该节点确认「风险连接」。
- **风险**：流量为明文或不加密，例如没有 TLS 的 VLESS / Trojan、不加密的 VMess 或 Shadowsocks、SOCKS / HTTP、无密码的 Hysteria2。可以运行，但连接前会提示。
- 可以在节点列表按风险筛选。设置中的「允许所有风险节点直接连接」默认关闭，打开后不再逐个确认，请谨慎使用。

# 检测中心 {#diagnostics}

检测中心可以对以下目标逐步检测 DNS 解析、TCP 连接、TLS 握手和 HTTP 请求，并显示每一步耗时与失败位置：

- **Cloudflare**：默认 `https://www.cloudflare.com/cdn-cgi/trace`。
- **Claude**：默认 `https://api.anthropic.com/v1/messages`。只发送不带任何凭据的 GET 请求，用来判断网络是否可达；结果会写明「账户认证：未执行」。
- **自定义 URL**：默认填 `https://www.google.com/generate_204`，可改成任意地址。

两个默认目标都可以在设置中修改。检测结果会标明是「直连（VPN 未开启）」还是「经 VPN 隧道」，并保存在本机的检测历史中（默认保留 30 天，可在设置中调整）。

# 测速 {#speedtest}

测速支持 M-Lab ndt7（先向 `locate.measurementlab.net` 获取就近服务器）和 Cloudflare（`speed.cloudflare.com`），会先探测各服务器延迟再选择，也可以手动指定。结果包括延迟、抖动、下载和上传速率；丢包率等无法可靠测得的指标显示为「不支持」。

- M-Lab 会**公开**测试数据（包括你的 IP 地址和测试时间），详见 [M-Lab 隐私政策](https://www.measurementlab.net/privacy/)。
- Cloudflare 测速端点在连续测试时可能返回 HTTP 429（限流），稍后再试即可。
- 开启 VPN 时测得的是经过节点的速度，关闭时是直连速度。测速在手机上的准确性 ==待验证==。

# IP 信誉与自己的 AbuseIPDB Key {#reputation}

「出口 IP 与信誉」会先查询当前出口 IP（`api.ip.sb/geoip`，失败时改用 `ipinfo.io/json`），然后把这个 IP 发给 AbuseIPDB 查询滥用评分、举报数、ISP、国家、是否 Tor 等信息。同一个 IP 的结果在应用内缓存 30 分钟。

1.3.0 安装包内置了一个默认 AbuseIPDB Key。它随 APK 分发，所有用户共用同一个配额，也可能被他人提取。建议：

1. 在 [AbuseIPDB](https://www.abuseipdb.com/) 注册并创建自己的 API Key。
2. 在应用「设置」中填写。填写后优先使用你自己的 Key；Key 保存在 Android Keystore 保护的安全存储中。
3. 如果出现「配额已用尽或被限流（HTTP 429）」或「API Key 无效（HTTP 401/403）」，请检查或更换 Key。

# 常见问题与排查 {#faq}

## 安装时提示签名不一致 / 无法覆盖安装

你装的是 1.0.0 或 1.1.0。这两个版本与 1.1.1 及以后的版本使用不同的签名证书，必须先卸载旧版再安装（会清除应用数据）。

## 安装时提示「应用未通过安全检测」或被拦截

这是因为应用来自应用商店之外，并且使用 debug 签名。请确认 SHA-256 与下载中心一致后再决定是否安装。

## 连接后无法上网

1. 在检测中心用「自定义 URL」检测，看失败发生在 DNS、TCP、TLS 还是 HTTP 哪一步。
2. 打开 VPN，对节点做一次延迟检测，确认结果是「代理请求」层的成功，而不只是「仅 TCP」。
3. 切换到「直连模式」对比：如果直连模式可以上网，问题多半在节点本身或节点参数。
4. 检查节点是否被标为高风险而未确认（未确认的高风险节点不会进入运行配置）。

## 提示 `unknown uTLS fingerprint`

1.1.1 起已修复：不支持的指纹值（例如 `fp=unsafe`）会被忽略并给出诊断提示。如果仍遇到，请升级到最新版。

## 连接一直显示「连接中」

1.2.0 起，内核 30 秒内没有成功启动会自动停止，并显示「连接超时」。请到设置中「导出日志（已脱敏）」并在 GitHub Issues 反馈。

## 如何反馈问题

在 [GitHub Issues](https://github.com/WQQZachery/wq-s-vpn-proxy/issues) 提交。可以在应用「设置 → 导出日志（已脱敏）」复制日志，日志会隐藏订阅地址、密码、UUID、令牌等信息，但提交前仍建议自己检查一遍。
